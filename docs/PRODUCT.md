# Задача проекта

Статус (2026-10-14): MVP реализован и опубликован по ТЗ пользователя. Live: https://market-radar-ochre.vercel.app

## Цель и пользователь

Радар заказов для компании, которая делает сайты и приложения в Польше. Пользователь видит реальные публичные закупки: что нужно сделать, кто заказчик, срок подачи предложений, сумму (если указана) и ссылку на источник. Данные обновляются кнопкой на сайте, без участия агента.

## Источники данных (проверено 2026-10-14)

- **BZP — Biuletyn Zamówień Publicznych (платформа e-Zamówienia, UZP).** `GET https://ezamowienia.gov.pl/mo-board/api/v1/notice` — без ключа, ответ JSON, `Access-Control-Allow-Origin: *` (можно вызывать из браузера). Обязательные параметры: `PublicationDateFrom`, `PublicationDateTo`; полезные: `NoticeType=ContractNotice`, `CpvCode`, `PageSize` (до 500). Фильтр `CpvCode` ищет точный код среди кодов объявления, а не подкатегории, поэтому нужно несколько запросов по разным кодам. Поля: `orderObject` (что), `organizationName`/`organizationCity` (заказчик), `submittingOffersDate` (срок, UTC), `objectId` (для ссылки), `htmlBody` (полный текст). Ссылка: `https://ezamowienia.gov.pl/mo-client-board/bzp/notice-details/id/<objectId>`. Отдельного поля суммы нет: «Wartość zamówienia» есть в тексте примерно у 1 из 8 объявлений. Это закупки ниже порогов ЕС — основная часть небольших заказов на сайты.
- **TED — Tenders Electronic Daily (ЕС).** `POST https://api.ted.europa.eu/v3/notices/search` — без ключа, JSON, `buyer-country=POL`. Поле суммы есть (`estimated-value-lot`), но часто пустое. Это крупные закупки выше порогов ЕС. Ссылка: `https://ted.europa.eu/pl/notice/-/detail/<publication-number>`.

## Первая версия (реализовано)

- Одна статичная страница в `public/` (HTML/CSS/JS без сборки и без сервера).
- Кнопка «Обновить» запрашивает BZP прямо из браузера: объявления о закупках за последние 30 дней по набору IT-кодов CPV (72000000-5, 72200000-7, 72212000-4, 72262000-9, 72400000-4, 72413000-8 и др.), дубли убираются.
- Остаются только закупки с ещё не истёкшим сроком; сортировка по сроку (ближайшие сверху).
- Фильтр по ключевым словам (strona internetowa, portal, aplikacja, platforma, e-usługi…), который можно выключить и увидеть все IT-закупки.
- Таблица: что сделать, заказчик и город, срок, сумма (если найдена в тексте, иначе «—»), ссылка на источник.
- На потом: TED как второй источник, сохранение «интересно / не интересно», уведомления, история.

## Критерии готовности (проверено 2026-10-14)

- Нажатие «Обновить» на опубликованной странице загружает свежие закупки BZP без участия агента.
- В каждой строке есть пять полей; ссылка открывает то же объявление на ezamowienia.gov.pl.
- Нет закупок с истёкшим сроком; страница читается на ширине ноутбука и телефона.
- При ошибке API пользователь видит понятное сообщение, а не пустую таблицу.

| «Обновить» 2026-10-14 | Есть строка «…nowej strony internetowej dedykowanej przedsiębiorcom», Miasto Jasło, срок 2026-10-15, сумма «—» | Сравнить со страницей объявления |

## Подтверждённые решения

- 2026-10-14: пользователь дал ТЗ на MVP: BZP, таблица + фильтры + «Обновить данные», публикация в GitHub и Vercel; TED, списки, уведомления, аккаунты — не делать.
- Решение агента: статическая страница без сервера — BZP отдаёт `Access-Control-Allow-Origin: *`, проверено с домена Vercel. Состояние — localStorage браузера. Обновление «всё или ничего». Объявления без срока подачи не показываются.
