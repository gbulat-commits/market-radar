## Цель и решения

Радар публичных IT-закупок в Польше (сайты, приложения) из BZP. Детали — `docs/PRODUCT.md`. Статическая страница, запросы к BZP из браузера (CORS `*`), кэш последнего успешного результата в localStorage.

## Файлы

- `public/index.html`, `public/styles.css` — страница.
- `public/js/bzp.js` — адаптер источника: 15 кодов CPV, 30 дней, деление диапазона при 500 записях, общий лимит 4 запроса, таймаут 30 с, 1 повтор, «всё или ничего», извлечение суммы (разделы 4.1.5–4.1.6, оценка без VAT).
- `public/js/app.js` — интерфейс, фильтры, кэш.
- `public/js/simulate.js` — тестовый режим `?simulate=…` (тестовые данные помечены TEST, в кэш не пишутся).
- `tests/index.html` — тесты адаптера в браузере (не деплоятся).

## Фактические проверки (2026-10-14)

- Тесты адаптера: 16/16 PASS (локально, `http://localhost:5173/tests/`).
- Локально и на live: реальная загрузка — 15 запросов к BZP, ~4 с, 240 IT-закупок, 94 открытых, 16 по теме; контрольный пример Kompas Kariery — 231 300,81 PLN, срок 22.10.2026 10:00.
- Двойной клик — один цикл запросов. Ошибки network/http/format/partial/timeout/empty — сообщение, прежние данные и время сохраняются (локально; http — и на live).
- Live: все файлы совпадают с коммитом по sha1; `/AGENTS.md`, `/docs/HANDOFF.md`, `/tests/index.html`, `/.env.example` → 404; консоль без ошибок; мобильная ширина 375 px без горизонтальной прокрутки.
- Независимое ревью перед публикацией: «публиковать»; исправлены лимит запросов, фильтр без срока, проверка кэша, обновление сроков, разбор дат.

## Запуск

`python -m http.server 5173` в корне → `http://localhost:5173/public/`. Переменные окружения не нужны.

## Ограничения

- У BZP нет публичной спецификации API; формат определён по реальным ответам.
- Сумма есть примерно в 1 из 8 объявлений (только в тексте).
- Объём загрузки ~10 МБ на обновление (полный текст объявлений приходит в ответе).
