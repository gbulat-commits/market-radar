# Установка Workshop Starter v0.2.8

Один пакет для Windows и macOS, для Codex и Claude Code. Пути относительны папке проекта.

## Сценарий А: новый проект

Распакуйте ZIP, найдите папку, непосредственно содержащую `AGENTS.md`, переименуйте её в имя проекта, перенесите в папку проектов и откройте в агенте как локальный проект. Режим: Claude Code — Auto; Codex — доверие к папке и Approve for me. Затем отправьте:

```text
Сначала проверь, что AGENTS.md лежит прямо в этой папке; если нет — назови, какую папку открыть, и остановись.
Подготовь Workshop Starter в текущей папке к работе по INSTALL.md.
Прочитай правила, примени workshop-copilot и проверь установку.
Глобальные настройки не меняй. Помоги согласовать первую версию проекта.
```

## Сценарий Б: есть свой проект или настройки

Не распаковывайте архив поверх существующих файлов. Держите Starter в отдельной папке, откройте свой проект и отправьте:

```text
Сравни Workshop Starter из папки
[полный путь к распакованному Starter]
с правилами и настройками текущего проекта.
Пока ничего не меняй. Предложи минимальное объединение:
что сохранить, что добавить и какие конфликты решить.
Сохрани код, память проекта и ограничения безопасности.
Глобальные настройки не меняй. Покажи конкретные правки для согласования.
```

## Порядок для агента

1. Проверь, что в корне открытой папки есть все 17 файлов пакета, включая скрытые `.agents`, `.claude`, `.codex`, `.gitattributes`. Если `.codex/` появился в уже открытой папке Codex, предложи начать новый чат — иначе его config и rules не действуют.
2. В сценарии Б ничего не перезаписывай: покажи план объединения, сохрани код, память, более строгие ограничения и правила Git; правь только после согласия, с возможностью восстановления.
3. Не меняй глобальные настройки, не устанавливай программы, не создавай Git и не публикуй в рамках установки.
4. Прочитай `AGENTS.md`, `docs/PRODUCT.md`, `PLANS.md`, `docs/HANDOFF.md` (в Claude Code также `CLAUDE.md`) и примени `workshop-copilot`; если skill не виден — прочитай его `SKILL.md` и скажи об этом.
5. Отчитайся в четыре строки: папка и состав; правила и skill; известный режим разрешений и конфликты (чего не знаешь — так и скажи); что нужно от пользователя или первый вопрос о задаче.
6. Помоги сформулировать задачу. При пустом `docs/PRODUCT.md` не придумывай продукт и стек; до согласования приложение не создавай.
